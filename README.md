# RT6 Sim releases

Update files for the fan-made Ruitoo RT6 scooter sim (non-commercial; Ruitoo, RT6 and the Ruitoo logo belong to Ruitoo, who keep all rights to them, and this project is not affiliated with or endorsed by Ruitoo).
The Android app reads `update.json` on launch and downloads `rt6.html` when it is newer (checked against its SHA-256).
To install the app: download `RT6Sim.apk`.

Current version: **2026.1122.1233** - Crown in front of the Ruitoo plates, light cable outside them, rounded front fender, cables go up inside the stem and into the deck, thicker deck, new jacket, floating fork bolts removed
